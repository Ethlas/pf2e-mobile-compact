Mobile Sheet Style Guide

The colours, utility classes and components of styles/pf2e-mobile.css, rendered with the real stylesheet. Class names are shown under each sample.

  • Use a palette variable (--m-*) for every background, border and text colour. Need a colour that is not here? Add it to the Colour Palette block and to this page, instead of writing a hex value in a component rule.
  • Layout and text size/weight in templates use the m-* utilities (flex, gap, truncate, m-text-*, m-medium/m-semibold/m-bold, m-color-*). Component rules keep only how something looks.
  • Every badge takes one badge class: m-badge (the shape), or m-badge-neutral (the same shape with the neutral look) for badges without a role colour. Size and colour of the text come from m-text-* and m-color-*. Badges and soft buttons of a role use that role's tone; solid action buttons use its -solid shades. Add a new badge's selector to the tone rule at the end of the stylesheet.
  • Damage types, proficiency ranks and character tags use pf2e's colours; the role colours follow Foundry's.
  • When you add or change a variable, utility, component or colour role, update this page in the same change.
